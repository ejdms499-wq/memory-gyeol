Recall First · Memory Reconstruction
01 · FIRST RECALL

기억의 시작은
떠오르는 그대로.

완벽하게 기억하려고 하지 않아도 괜찮아요. 확실한 것과 확실하지 않은 것을 섞지 않고 지금 떠오르는 첫 기억부터 천천히 따라갈게요. 기억결은 빈 부분을 마음대로 채우기보다, 기억하고 있는 것과 기억하지 못하는 것의 경계를 그대로 남기는 데서 시작해요.

STEP 01

처음 떠오르는 기억

정확한 날짜나 장소를 모르더라도 괜찮아요. 지금 생각나는 장면을 말하듯 적어주세요.

0 / 1500
날짜, 사람, 장소가 정확하지 않아도 괜찮아요. “~였던 것 같아”, “잘 기억나지 않아” 같은 표현도 그대로 적어주세요.

입력한 기억은 재구성 인터뷰를 시작하기 위한 최초 기억으로 사용돼요.

MEMORY GYEOL · 기억 재구성 프로젝트 기억하지 못하는 것은 기억하지 못하는 채로.
