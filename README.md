# 기억결 — Memory Gyeol

> **기억을 채우지 않고, 기억의 결을 따라가요.**

기억결은 사용자가 떠올린 기억을 AI가 임의로 완성하는 대신,  
**확실한 기억 / 불확실한 기억 / 기억하지 못하는 정보의 경계**를 보존하면서  
질문과 이미지 재구성을 통해 하나의 장면을 다시 따라가는 AI 기억 재구성 서비스입니다.

## 01. Project Overview

일반적인 생성형 AI는 정보가 부족할 때도 그럴듯한 내용을 만들어낼 수 있습니다.

하지만 사람의 기억을 다루는 서비스에서  
AI가 빈 부분을 자연스럽게 채워버리면 사용자가 실제 기억과 AI가 만든 정보를 혼동할 가능성이 있습니다.

기억결은 이 문제에서 출발했습니다.

### Recall First

기억결의 핵심 원칙은 **Recall First**입니다.

AI가 먼저 장면을 만들어내는 것이 아니라,

**사용자가 먼저 떠올린 기억을 보존하고  
그 기억 안에서 확실한 것과 확실하지 않은 것을 구분한 뒤  
확인된 범위 안에서만 재구성합니다.**

---

## 02. Core Concept

기억결은 기억을 세 가지 상태로 구분합니다.

### ● Confirmed Memory

사용자가 확실하게 기억한다고 말한 정보

예:

- 초등학생 때
- 학교 운동장
- 친구와 함께 있었음
- 크게 웃었음

### ○ Uncertain Memory

사용자가 "~였던 것 같다", "확실하지 않다"라고 표현한 정보

예:

- 친구가 먼저 공을 던졌던 것 같음
- 공을 받았던 것 같음
- 주변 모습은 잘 기억나지 않음

### Unknown

사용자가 말하지 않았거나 기억하지 못하는 정보

예:

- 친구의 얼굴
- 머리 모양
- 옷 색
- 정확한 시간대
- 날씨
- 학교 건물 구조
- 주변 시설

이 정보는 이미지 생성 과정에서 임의의 기억 사실로 추가하지 않는 것을 원칙으로 합니다.

## 03. User Flow

```text
사용자가 최초 기억 입력
        ↓
First Recall 저장
        ↓
AI 비유도형 기억 인터뷰
        ↓
확실 / 불확실 기억 분리
        ↓
기억 재구성 분석
        ↓
Memory Image Guard
        ↓
Final Prompt Lock
        ↓
AI 이미지 생성
        ↓
Private Storage 저장
        ↓
Signed URL 발급
        ↓
결과 페이지
